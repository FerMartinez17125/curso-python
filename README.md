# Curso de Python

Repositorio de ejercicios y prácticas realizados durante mi aprendizaje de Python.

## Objetivos

- Practicar los fundamentos del lenguaje Python.
- Organizar los ejercicios por secciones del curso.
- Aprender a utilizar Git y GitHub.
- Mejorar los ejercicios mediante pruebas y experimentos propios.

## Estructura inicial

- `Hello_world.py`: primer programa en Python.
- `INTRODUCCION/`: ejercicios correspondientes a la sección de introducción.
- `.vscode/launch.json`: configuración para ejecutar el archivo abierto en una terminal externa.

## Ejecución

Para ejecutar un archivo desde la terminal:

```powershell
python .\ruta\al\archivo.py
```

También se puede abrir el archivo en VS Code y presionar `F5` para utilizar la configuración de ejecución externa.
